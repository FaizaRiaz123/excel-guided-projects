# 📊 Excel Guided Practice Projects

This repository contains **Excel projects I completed as guided practice**
while following the **11-hour Excel tutorial by Luke Barousse**.

These projects helped me strengthen my Excel fundamentals and apply them to
realistic, business-style datasets.

> ⚠️ **Note:**  
> The project ideas and datasets originate from Luke Barousse’s tutorial.  
> All analysis, dashboards, and implementation were completed by me as part of hands-on learning.

---

## 🧠 Skills Practiced

- Data cleaning and formatting  
- Excel formulas (IF, XLOOKUP, COUNTIFS, SUMIFS)  
- Pivot Tables & Pivot Charts  
- Power query, DAX & Power pivot
- Dashboard layout and formatting  
- Data analysis for business insights

- Analyzed salary trends across roles and experience levels
